# Roadmap

## MVP

1. **Вход стримера** через Twitch OAuth и 2FA (TOTP) на стороне сайта.
2. **Профиль стримера** — публичная страница `/<twitch-login>` с текущими ивентами.
3. **Создание ивента** в админ-панели: название, описание, приз(ы), сроки,
   обязательные контакты (Telegram / VK), лимит участников.
4. **Персональная ссылка** на ивент, которую стример даёт зрителям.
5. **Участие**: вход через Twitch (обязательно) + привязка Telegram и/или VK
   (по настройке ивента). Одна заявка на один Twitch ID.
6. **Розыгрыш**: случайный выбор победителя, показ его Twitch-ника и приза,
   перевыбор при неявке.
7. **Список участников** для стримера: Twitch ID, ник, контакты, время входа.
8. **OBS-оверлей**: браузерный источник со страницей розыгрыша, базовая кастомизация
   (цвета, шрифт, фон).
9. **RU/EN** интерфейс.
10. **Правила участия и политика конфиденциальности**.
11. **Docker Compose** для запуска всего проекта.

## После MVP

- Другие типы ивентов: голосование, викторина, по очкам канала.
- Доказуемо честный розыгрыш (публикация seed и хеша).
- Несколько вариантов оверлеев и редактор оверлеев.
- Фильтры участия: подписчики, follow, возраст аккаунта.
- Страница поддержки проекта донатами.
