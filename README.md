## Что это?

**Kontesai** — бесплатный веб-сайт, на котором стример создаёт ивент с призами,
раздаёт зрителям персональную ссылку и проводит розыгрыш прямо на стриме.

Сайт **объявляет победителя** (его Twitch-ник и выигранный приз) и передаёт стримеру
контакты победителя. Выдачей приза занимается сам стример.

> ⚠️ Проект на ранней стадии: пока готов только каркас репозитория.
> План работ — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Как это работает

### 🎙️ Стример
1. Входит на сайт через **Twitch** и включает **2FA**.
2. Получает публичный профиль со своими ивентами.
3. В **админ-панели** создаёт ивент: тип, приз(ы), сроки, обязательные контакты участников.
4. Делится **персональной ссылкой** на ивент со зрителями.
5. Запускает розыгрыш и показывает его на стриме через **OBS-оверлей**.

### 👥 Участник
1. Переходит по ссылке стримера.
2. Входит через **Twitch** (обязательно).
3. Привязывает **Telegram** и/или **VK**, если этого требует ивент: так стример сможет связаться с победителем.
4. Ждёт результатов. Один Twitch-аккаунт — одна заявка.

## Технологии

- **Frontend:** Next.js, TypeScript
- **Backend:** Node.js, Fastify, TypeScript
- **База данных:** PostgreSQL + Prisma
- **Авторизация:** Twitch OAuth 2.0, Telegram Login Widget, VK ID
- **Инфраструктура:** Docker, Docker Compose
- **Монорепозиторий:** pnpm workspaces

## Локальный запуск

> Приложения `web` и `api` ещё не созданы — сейчас запускается только база данных.

**Требования:** Node.js 22+, pnpm 9+, Docker.

```bash
git clone https://github.com/Arkomiko/Kontesai.git
cd Kontesai
cp .env.example .env        # заполнить POSTGRES_PASSWORD и ключи
docker compose up -d db
pnpm install
```

Ключи для `.env`:
- **Twitch** — приложение в [Twitch Developer Console](https://dev.twitch.tv/console/apps)
- **Telegram** — бот через [@BotFather](https://t.me/BotFather)
- **VK ID** — приложение в [VK ID](https://id.vk.com/about/business)
